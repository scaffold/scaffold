Every new free-market block adds it's work to the claim weight of every ancestor.
Can propagate this with one of 3 methods:
  1. Local CITEs with covering: Every time a peer receives a new block, propagate work up
    With this, at any interval in time after a new peer joins, if an attacker manages to over-compute the rest of the network, the new peer can think that a different branch is canonical. But that's fine, because eventually the rest of teh network will keep computing on the correct branch
  2. Universal CITEs: Can vouch for CITEs
